# Finalverse 0.4.0-preview.2

**Mac startup hotfix for the experimental developer preview.** This replaces
preview.1 for new installations. It is not a GA release or a notarized Mac beta.

## Fixed

On macOS, opening the downloaded preview could display **Missing Files**, then
**MissingString(MBFatalError)** and an error loading `settings_files.xml`. The
file was present and the downloaded DMG matched the published checksum.

The inherited POSIX file reader incorrectly requested file creation (`O_CREAT`)
for input-only reads. macOS AppTranslocation's read-only nullfs rejects that
request even when the file already exists. Input-only reads now use read-only
flags. Output-file creation behavior and the Windows implementation are retained.

XML diagnostics now preserve the operating-system read error, the early fatal
dialog has a usable title before translations load, and the missing-files dialog
links to Finalverse's releases and issue tracker.

## Regression protection

- A unit test checks that input-only reads fail without creating a missing file.
  It failed before the fix and passes afterward.
- The native resource probe uses the same C++ reader as the viewer. Against the
  original protected AppTranslocation mount, eight required startup resources
  failed with EROFS before the fix and all eight were readable afterward.
- Packaging requires that native probe, checks required XML and resource hashes,
  and verifies the staged app and exact mounted read-only DMG. A writable developer
  copy alone is insufficient acceptance evidence.

The corresponding source, dependency sources, checksums and build provenance
accompany the GitHub prerelease. The engine version remains 26.4.0; this preview
uses build **54622**.

## Install and scope

Download the new DMG from the
[GitHub prerelease](https://github.com/finalverse/final_viewer/releases/tag/v0.4.0-preview.2),
verify its checksum, drag **Finalverse Preview.app** to **Applications**, eject
the disk image, and open the installed app. Preserve your existing user profile;
deleting preferences or world data is not part of this fix.

The app has an ad hoc integrity signature, without Apple Developer ID signing or
notarization. macOS can still block opening it. Follow macOS's per-app approval
process only if you trust this experimental preview; never disable Gatekeeper
globally. That separate distribution gate remains open.

The feature and access scope is unchanged from
[preview.1](0.4.0-preview.1.md): invited world access, no bundled credentials,
Apple Silicon runtime acceptance with Intel hardware unverified, hosted AI
subject to world capabilities and permissions, manual updates, optional libVLC
playback excluded and voice off by default. This hotfix does not certify wider
device, load, onboarding or final-art gates.
