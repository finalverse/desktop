# Finalverse 0.4.0-preview.1

**Experimental Mac developer preview for developers and invited testers.**
Not a GA release, public-world launch or signed/notarized Mac beta.

The Finalverse milestone version is independent of the inherited viewer engine
version (26.4.0); exact engine/build/source values accompany the release assets.

## Included

- Existing desktop world connectivity, avatars, inventory, editing and rendering.
- Finalverse's Mac facade, Create, recipe Save/Load/Remix and capability-aware UI.
- Authenticated hosted planning and bounded deterministic spatial placement.
- Hosted Lumi co-building with reviewed approval, persistent PostgreSQL memory,
  recorded execution and guarded Undo for the configured controller.
- Grid-aware discovery/help and the existing protection against sending an
  explicit unknown grid's credentials to a fallback service.

The [native demonstration](../demos.md) records the actual private pilot
creation/Undo. Availability depends on the connected world's advertised
capabilities and the account's permissions.

## Distribution and access limits

| Item | Preview scope |
|---|---|
| Platform | Universal Mac executable; Apple Silicon runtime checked. Intel hardware unverified. No Linux/Windows/mobile binary. |
| Signing | Ad hoc signature; no Developer ID distribution identity or notarization. macOS may block opening. |
| Account | No shared credentials or automatic registration. Private Harbor access requires an invitation and operator-provisioned account/window. |
| AI | Hosted gateway/runtime; no cloud API secrets in the app. One configured Lumi controller; no public multi-user ownership service. |
| Updates | Manual GitHub downloads. No automatic updater. |
| Media/voice | The staged public package excludes optional libVLC/codec playback until its corresponding-source inventory closes. Voice defaults off and is not preview-certified. The full source/development build retains both implementations. |
| Stability | Experimental. Back up profiles/worlds; no public SLA. Voice, broader device/load behavior and final art are not release-certified. |
